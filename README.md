# MATLAB/Octave Power Flow Analysis Toolbox

Полный набор инструментов для анализа установившихся режимов электрических сетей в среде GNU Octave/MATLAB. Включает методы Ньютона-Рафсона, Гаусса-Зейделя, Якоби, моделирование ZIP-нагрузок, оптимизацию коэффициентов трансформации, анализ N-1 и суточные графики нагрузки.

## ✨ Возможности

### Основные методы расчёта
- **Метод Ньютона-Рафсона** с полярными координатами и автоматическим переключением PV/PQ
- **Метод Гаусса-Зейделя** с регулируемой верхней релаксацией (1.2–1.8)
- **Метод Якоби** для сравнения и обучения
- **Метод продолжения по параметру** для построения PV-кривых
- Поддержка балансирующих, PV и PQ узлов

### Моделирование сети
- **Формирование матрицы Y_bus** двумя способами:
  - Непосредственное суммирование проводимостей
  - Через обобщённую матрицу инцидентности
- Поддержка элементов:
  - Линии электропередачи (П-образная схема)
  - Двухобмоточные трансформаторы с коэффициентом трансформации
  - Трёхобмоточные трансформаторы (автотрансформаторы)
  - Шунтирующие элементы (конденсаторы, реакторы)

### Модели нагрузки
- **ZIP-модель** (постоянные: полное сопротивление, ток, мощность)
- Проверка нормировки коэффициентов
- Эквивалентирование группы нагрузок
- Суточные графики нагрузки

### Расширенный анализ
- **Критерий N-1** (отключение ветвей)
- **Суточные расчёты** с определением потерь энергии
- **Оптимизация коэффициента трансформации** для минимизации потерь
- **PV-кривые** для оценки устойчивости по напряжению
- **Сценарный анализ** с произвольными условиями

### Визуализация и отчётность
- Профили напряжений
- История сходимости (полулогарифмический график)
- Векторные диаграммы
- Автоматическая генерация отчётов (текстовый формат)
- Анализ загрузки ветвей с индикацией состояния

## 🚀 Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/yourusername/octave-power-flow-toolbox.git
   cd octave-power-flow-toolbox
   ```

2. **Добавьте путь в Octave:**
   ```octave
   addpath(genpath('path/to/octave-power-flow-toolbox'));
   savepath;
   ```

3. **Проверьте установку:**
   ```octave
   which power_flow_newton
   ```

## 🏃 Быстрый старт

### Базовый расчёт режима
```octave
% Определение сети (3 узла)
Z12 = 0.02 + 1i*0.08;
Z13 = 0.03 + 1i*0.10;
Z23 = 0.025 + 1i*0.09;

y12 = 1/Z12; y13 = 1/Z13; y23 = 1/Z23;

Ybus = [ y12+y13,  -y12,     -y13;
         -y12,      y12+y23, -y23;
         -y13,     -y23,      y13+y23];

% Описание узлов
buses(1).type = 'SLACK';
buses(1).U_set = 1.05;
buses(2).type = 'PV';
buses(2).P = -0.5;      % генерация
buses(2).U_set = 1.02;
buses(2).Q_min = -0.4;
buses(2).Q_max = 0.6;
buses(3).type = 'PQ';
buses(3).P = 0.8;       % нагрузка
buses(3).Q = 0.4;

% Расчёт методом Ньютона-Рафсона
[U, iter, conv, hist] = power_flow_newton(Ybus, buses, 1e-8, 50);

% Вывод результатов
printf('Сходимость за %d итераций\n', iter);
for i = 1:3
    printf('Узел %d: |U| = %.4f о.е., θ = %.2f°\n', ...
        i, abs(U(i)), angle(U(i))*180/pi);
end
```

### Расчёт с ZIP-нагрузкой
```octave
% Коэффициенты ZIP [zp, ip, pp, zq, iq, pq]
zip = [0.22, 0.02, 0.76, 0.15, 0.09, 0.76];

% Проверка нормировки
if check_zip_coefficients(zip)
    % Расчёт мощности при фактическом напряжении
    [P, Q] = get_zip_power(10e6, 5e6, 105e3, 110e3, zip);
end
```

### Суточный расчёт режима
```octave
% 24-часовой график нагрузки
k_profile = [0.65, 0.60, 0.58, 0.55, 0.57, 0.65, ...
             0.75, 0.85, 0.95, 1.00, 1.00, 0.98, ...
             0.95, 0.97, 1.00, 1.00, 0.95, 0.90, ...
             0.85, 0.80, 0.75, 0.72, 0.70, 0.68];

[P_loss, W_daily, U_min] = daily_load_flow(Ybus, buses, branches, k_profile);
```

## 📐 Теоретическая основа

### Уравнения невязок (метод Ньютона-Рафсона)

**Невязка активной мощности** (для PQ и PV узлов):
```
ΔP_i = P_i_зад - V_i * Σ(V_j * (G_ij*cos(θ_i-θ_j) + B_ij*sin(θ_i-θ_j)))
```

**Невязка реактивной мощности** (только для PQ узлов):
```
ΔQ_i = Q_i_зад - V_i * Σ(V_j * (G_ij*sin(θ_i-θ_j) - B_ij*cos(θ_i-θ_j)))
```

### Матрица Якоби

```
[ ΔP ]   [ H  N ] [ Δθ ]
[ ΔQ ] = [ M  L ] [ ΔV/V ]
```

Где:
- **H** = ∂(ΔP)/∂θ (размер: n_PQPV × n_PQPV)
- **N** = ∂(ΔP)/∂V * V (размер: n_PQPV × n_PQ)
- **M** = ∂(ΔQ)/∂θ (размер: n_PQ × n_PQPV)
- **L** = ∂(ΔQ)/∂V * V (размер: n_PQ × n_PQ)

### ZIP-модель нагрузки

Объединяет три типа нагрузки:
```
P = P₀ · (z_p·V² + i_p·V + p_p)
Q = Q₀ · (z_q·V² + i_q·V + p_q)
```

Условие нормировки коэффициентов:
```
z_p + i_p + p_p = 1
z_q + i_q + p_q = 1
```

### Формирование матрицы Y_bus

**Для линии электропередачи:**
```
Y_ii = y_серия + 0.5·y_шунт
Y_ij = -y_серия
```

**Для двухобмоточного трансформатора:**
```
Y_ii = y_серия + y_шунт
Y_jj = y_серия·k²
Y_ij = -y_серия·k
```
